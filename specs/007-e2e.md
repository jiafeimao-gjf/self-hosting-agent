# SPEC-007 端到端垂直切片（P0 验收）

状态：**已实现**

前面六份规格分别在测「一个部件」。这一份测**它们串起来还成不成立**——这是 P0 唯一的验收口径：

> 人类能否在不重启、不升级的前提下，让 Agent 把一个界面改动真的落到自己眼前。

链路：`CLI/宿主 → AgentPool → 子进程(agent-main) → AgentLoop 五步 → ui.patch 帧 → SurfaceIngest → ViewDocument → HTML`

## 验收标准

- **E2E-001** 端到端成立：Kernel 拉起 Loop 子进程，`human.message` 进去后，宿主能收到 `ui.patch`，界面文档产生新版本，并能渲染出含该面板的 HTML。
- **E2E-002** 非法 View Spec 被 `SurfaceIngest` 拒绝：不进入界面文档（版本不前进）、留下 rejected 记录，且**界面依然可用**。
- **E2E-003** 回滚：连续应用多次 patch 后可回到任意历史版本，渲染结果随之回退（架构里的「可回滚的改造权」）。
- **E2E-004** CLI 可独立跑通：`node src/cli.ts demo` 作为真实进程执行到底，退出码为 0，并落盘 `surface.html` 与 `surface.json`。
