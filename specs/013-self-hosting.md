# SPEC-013 客户端自举（P3）

状态：**已实现**

前两个阶段里，Agent 改的是**界面**（View Spec）。这一阶段它改的是**界面代码本身**——`src/client/**`。

这件事听起来很危险，所以它必须比别的功能更受约束：

> **Agent 可以改自己的代码，但改完必须自己通过项目自己的测试，否则自动回滚。**

于是「自举」不是一句宣言，而是一条可执行的链路：**改 → 自检 → 通过则生效 / 失败则回滚 → 人类可审阅可回滚**。

## 1. 宿主工具

| 工具 | 参数 | 说明 |
| --- | --- | --- |
| `client.list` | — | 列出可改文件与各自版本数 |
| `client.read` | `path` | 读一个文件（限 `src/client/**`，有大小上限） |
| `client.write` | `path`, `content`, `reason`, `append?` | 写一个文件，**过审批门**，写完跑自检 |
| `client.revert` | `path`, `version?` | 回滚到上一版或指定版本 |

## 2. 写作用域

可写根目录**只有** `src/client/`。以下一律拒绝：

- 任何解析后落在根目录之外的路径（`../`、绝对路径、编码绕过）
- 目录穿越到 `src/server/`、`src/kernel/`、`test/`、`package.json` 等

**Agent 能改自己的界面，不能改监管它的内核**——否则「闸门」这个词就没有意义了。

## 3. 自检门禁

写入不是直接落盘，而是：

```
写临时内容 → ①语法自检（node --check，每个改动的 .js）
           → ②项目自检（node --test test/client-ui.test.ts）
           → 通过：落盘 + 记版本 + 广播
           → 失败：原样回滚，文件内容不变，错误如实返回给 Agent
```

关键点：**失败不留下半成品**。Agent 想改代码，可以；想改坏，不行。

## 4. 版本与差异

- 每次成功写入产生一个版本（`v1`, `v2`…），历史落盘在 `<runDir>/client-history/`
- 每个版本记录：路径、时间、reason、作者、自检结果、内容快照
- `diff(path, version?)` 给出人类可读的逐行差异（`+` / `-`）

## 5. 广播与热更新

写入成功或回滚后，服务端通过 SSE 广播 `client.changed`：

```
event: client.changed
data: {"kind":"write","path":"style.css","reason":"...","selfTest":"passed","version":2,"diff":{"added":2,"removed":0}}
```

浏览器端据此：

- `.css` → **无刷新**替换 `<link>` 的 href（加 cache-bust 查询），主题即时生效
- `.js` / `.html` → 显示一条"客户端代码已更新，刷新以生效"的横幅（一键刷新）
- 任何变更都进事件时间线

`/api/state` 增加 `sources: [{path, bytes, versions}]`，供检查器展示。

## 验收标准

- **SELF-001** 写作用域：`src/client/**` 内允许；`../`、绝对路径、其它目录一律拒绝且不落盘。
- **SELF-002** `read` 同样受作用域与大小上限约束；不存在的文件返回明确错误。
- **SELF-003** `list` 返回可改文件、字节数与版本数。
- **SELF-004** 写入成功后文件内容更新、版本号 +1、历史留快照。
- **SELF-005** 版本历史可读，能给出人可读 diff（新增/删除行数与被改的行）。
- **SELF-006** 自检通过才落盘：自检失败时文件内容**与写入前逐字节一致**（自动回滚）。
- **SELF-007** 语法错误（`node --check` 失败）同样触发回滚，且错误信息可读。
- **SELF-008** `client.write` 过审批门：默认拒绝时不写文件、不进历史。
- **SELF-009** 审计：每次写入 / 回滚都写事件日志（含 path、reason、自检结果）。
- **SELF-010** 回滚：`revert` 把文件恢复为上一版内容，并广播 `client.changed{kind:'revert'}`。
- **SELF-011** 广播：写入成功与回滚都产生 `client.changed`；`/api/state` 的 `sources` 同步更新。
- **SELF-012** 无变化写入是幂等的：内容与当前一致时不产生新版本。
- **SELF-013** `append` 模式：在文件末尾追加内容（不必先读全文），且同样走自检门禁。
