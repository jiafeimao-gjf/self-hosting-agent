# SPEC-021 工作空间与动态加载

状态：**已实现**

## 它解决什么

Agent 干活时经常要留下东西：一份报告草稿、一段数据、一个配置、一张导出的表。在补齐之前它只有两个出口——说在对话里，或者画进界面文档——**都不持久**：换个对话就没了，也没法让人拿走去用。

工作空间给每个对话一块**真实存在磁盘上的目录**：

```
.agent-client/<run>/conversations/<id>/workspace/
```

Agent 通过宿主工具读写它，人类在「文件」页签里看到文件列表，点开即**动态加载**内容（不是把所有文件内容塞进状态里推给所有人）。

「工作空间模式」指的是：文件操作被限制在**这个目录内**，且每一次写入都留痕（谁写的、写了多少字节）。

## 一、路径安全（本规格的核心）

不可信输入是 `path`。规则只有一条：**任何路径都必须解析后仍落在工作空间根目录之内**。

- 绝对路径、`..`、符号链接穿越，一律拒绝（`PATH_ESCAPE`）；
- 空路径、以 `/` 结尾、包含 NUL 的路径拒绝；
- 目录深度与总字节数有上限，超过则拒绝（`WORKSPACE_FULL`）；
- 拒绝时就**不产生任何副作用**（不留半个文件）。

## 二、宿主工具（Agent 用）

| 工具 | 参数 | 行为 |
| --- | --- | --- |
| `workspace.write` | `path, content, append?` | 写文件（必要时建目录），返回字节数；超限拒绝 |
| `workspace.read` | `path` | 读文件，返回内容与是否截断 |
| `workspace.list` | — | 列出文件（路径、字节数、修改时间） |

工具名同样受 SPEC-009 的线上约束影响：内部名带点，出网压成 `workspace_write` 等。

## 三、HTTP 契约（冻结）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/workspace?conversation=<id>` | `{ok, root, files:[{path,bytes,mtime}]}`（**只列目录，不返回内容**） |
| GET | `/api/workspace/file?conversation=<id>&path=<p>` | `{ok, path, bytes, content, truncated}`：按需加载单个文件 |
| GET | `/api/history?conversation=<id>` | 已保存的历史文件列表（SPEC-020 的 `/history`） |
| GET | `/api/history/file?conversation=<id>&name=<n>` | 按需加载单个历史文件内容 |

**动态加载**的含义就是：`/api/workspace` 只给元信息，内容走 `/api/workspace/file`。叶子节点按需取，
避免状态快照随文件增长而膨胀（这是 SPEC-018 里"状态只推变化"的延续）。

## 四、客户端

- 右栏第三个页签「文件」：列出工作空间文件（路径、大小、时间），点击**动态加载**内容并展示；
- 无文件时显示空态；加载失败显示原因而不是白屏；
- 内容按纯文本渲染（`textContent`），不执行、不解析成 HTML；
- 单文件过大时显示「已截断」提示。

## 验收标准

- **WS-001** 工作空间根目录在 `<dir>/conversations/<id>/workspace` 下，首次写入时自动创建。
- **WS-002** `workspace.write` 写入成功返回字节数；`append: true` 追加而不是覆盖。
- **WS-003** 路径穿越一律拒绝：`../x`、`a/../../x`、绝对路径、`..` 单独一段都不能写出根目录之外。
- **WS-004** 拒绝时无副作用：被拒的写入不留文件、不改已有文件。
- **WS-005** 单文件与总量有上限，超限返回 `WORKSPACE_FULL` 且不写半个文件。
- **WS-006** `workspace.read` 读到不存在的文件返回明确错误码；超大文件读取时截断并标记。
- **WS-007** `workspace.list` 只列元信息（路径/字节/时间），**不返回文件内容**。
- **WS-008** `GET /api/workspace/file` 按需加载：内容参与本次响应，但**不出现在** `/api/state` 快照里。
- **WS-009** 越界或非法路径的 HTTP 请求返回 400 且不泄漏根目录之外的任何信息。
- **WS-010** 客户端「文件」页签：列出文件、点击动态加载、空态与错误态都不白屏、内容以纯文本渲染。
- **WS-011** 工作空间隔离：对话 A 写的文件在对话 B 的文件列表里看不到。
- **WS-012** **按对话隔离的接口必须带对话参数**：文件列表、文件内容、浏览器打开三处一律带 `?conversation=<id>`，
  且用的是**同一个**对话 id（面板的 `current`）。真 bug：`/api/browser/open` 漏了参数 → 服务端回落到默认对话
  → 在别处找不到文件（c2 里的 `universe.html` 报 NOT_FOUND）；失败也必须留痕（哪个对话、哪个路径、哪个工作空间）。
